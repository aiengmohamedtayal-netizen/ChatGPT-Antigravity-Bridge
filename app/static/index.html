Connecting ChatGPT to Antigravity

ChatGPT functions as the Lead Architect & Brain. By configuring a Custom GPT Action with the Bridge's OpenAPI spec, ChatGPT can dispatch coding prompts, check task status, and maintain conversational sessions with Antigravity.

OPENAPI 3.1 ACTION SCHEMA URL
Loading...

Step-by-Step Setup in OpenAI GPT Builder

  1. Go to chatgpt.com → Explore GPTs → Create a Custom GPT.
  2. In Configure, name it: Antigravity Architect.
  3. Scroll to Actions → Click Create new action.
  4. Click Import from URL and paste the OpenAPI URL above (or paste the schema directly).
  5. Set Authentication to API Key → Auth Type: Bearer → Enter an API key from the API Keys page.
  6. Paste the Architect Instructions into the GPT's Instructions box.

Model Context Protocol (MCP) Server

The Bridge runs a native MCP server supporting both Remote HTTP/SSE and Stdio. Antigravity can connect directly to this MCP server to fetch repository context, store code artifacts, and report progress.

REMOTE MCP (SSE TRANSPORT)
http://127.0.0.1:8000/mcp/sse
STDIO COMMAND
python -m app.mcp.server

Antigravity mcp_config.json Configuration

Add this block to your ~/.gemini/antigravity/mcp_config.json to register the Bridge tools into Antigravity: 

{
  "mcpServers": {
    "antigravity-bridge": {
      "url": "http://127.0.0.1:8000/mcp/sse"
    }
  }
}
