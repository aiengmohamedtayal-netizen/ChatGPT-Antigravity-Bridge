                Python
                
              

              
import httpx

API_URL = "http://127.0.0.1:8000/api/v1"
API_KEY = "agb_live_YOUR_KEY"
HEADERS = {"Authorization": f"Bearer {API_KEY}"}

# 1. Dispatch prompt to local Antigravity Agent
payload = {
    "project_id": "proj_default",
    "prompt": "Create JWT authentication endpoints in app/api/auth.py",
    "priority": "high"
}
response = httpx.post(f"{API_URL}/tasks", json=payload, headers=HEADERS)
task = response.json()
print(f"Task Queued: {task['id']}")

# 2. Continue the exact same session multi-turn
continuation = httpx.post(
    f"{API_URL}/tasks/{task['id']}/continue",
    json={"prompt": "Now write unit tests with 100% coverage"},
    headers=HEADERS
)
print(f"Session Preserved: {continuation.json()['session_id']}")

Frequently Asked Questions

          
Developer Questions & Security

        


        

          

            

              How does ChatGPT communicate with my local machine securely?
              +
            

            

              The Bridge operates a local FastAPI server bound to 127.0.0.1:8000. For external access from chatgpt.com, an encrypted Cloudflare Tunnel (TLS 1.3) proxies HTTPS requests without opening incoming firewall ports. Every request is verified with constant-time SHA-256 Bearer tokens.
            

          


          

            

              Does my proprietary code leave my computer?
              +
            

            

              No. Antigravity runs entirely locally on your machine. Only the high-level task summaries, execution status, and files modified are exchanged with ChatGPT to provide conversational feedback.
            

          


          

            

              How does multi-turn session continuation work?
              +
            

            

              When ChatGPT calls continue_agent_session, the Gateway reuses the same conversation thread in Antigravity. This prevents cold starts and ensures subsequent refactorings have full awareness of prior edits.
            

          


          

            

              What happens if an agent command fails or hangs?
              +
            

            

              The Bridge includes automated process timeouts, cancellation propagation via cancel_agent_session, and an idempotency layer to avoid duplicate task executions.
